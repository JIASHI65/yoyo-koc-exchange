② 创作者：投稿

作品(work)按平台数据计分；showcase 每人每期只 +1 分。

→

③ 创作者：兑换

积分来自 point_logs 汇总；兑换生成 redemption_orders，扣分后余额下降。
查看积分
→
选择奖励钻石 / 礼品卡 / 周边
→
积分够 & 兑换开放？
→
生成兑换订单redemption_orders
→
等待发放
积分不足 / 兑换关闭 → 拦截，不生成订单

⑤ 管理端：奖励发放 / 发货

发货 = 系统内账务状态(标记+扣分)，物理物流在独立发货系统。重复发货不重复扣分。

→

→
交给发货系统
已发货
跳过 · 不重复扣分
批量发奖
同人同期同奖励去重防重复发放

⑥ 管理端：月结对账（只读）

只列异常、不自动改数据。人工确认后再处理。
