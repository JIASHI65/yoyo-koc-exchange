1
KOC前端测试 创作者角色
步骤 1.1：注册新账户

操作：

  1. 打开KOC前端页面
  2. 点击 "Register" 标签
  3. 填写测试信息：
    • Game UID：测试用ID（如 "TestUser001"）
    • Discord Name：你的Discord名字
    • System ID：19位数字（如 "1234567890123456789"）
    • Full Name：测试姓名
    • Address：测试地址
  4. 点击 "Register"

预期结果：

  • ✅ 显示"Registration successful"
  • ✅ 自动跳转到提交作品页面
  • ✅ 顶部显示你的UID和积分（0分）
步骤 1.2：提交作品（第1次）

操作：

  1. 在 "Submit Works" 标签
  2. 粘贴测试链接（每行一个）：
https://www.tiktok.com/@test/video/123 https://www.youtube.com/watch?v=test456
  1. 点击 "📤 Submit Works"
  2. 确认提交

预期结果：

  • ✅ 显示成功提示
  • ✅ 计数器显示 "Submissions used: 1/2"
步骤 1.3：查看已提交作品

操作：

  1. 点击 "My Submissions" 标签
  2. 查看提交记录

预期结果：

  • ✅ 看到刚才提交的链接
  • ✅ 状态显示：⏳ Pending
  • ✅ 积分显示：-（待评分）
步骤 1.4：第2次提交（验证限制）

操作：

  1. 返回 "Submit Works"
  2. 再次提交不同的链接

预期结果：

  • ✅ 提交成功
  • ✅ 计数器显示 "2/2"
  • ✅ 提交框和按钮变为禁用状态
  • ✅ 显示"You have reached the submission limit"提示
步骤 1.5：暂停，切换到Admin后台
ℹ️ 暂停KOC测试

现在需要切换到Admin后台，给这些提交打分并开启兑换功能。

2
Admin后台测试 管理员角色
步骤 2.1：登录后台

操作：

  1. 打开Admin后台页面
  2. 输入管理员密码
  3. 登录

预期结果：

  • ✅ 成功进入Dashboard
  • ✅ 看到顶部导航栏（Dashboard、作品审核、积分计算等标签）
步骤 2.2：查看待审核作品

操作：

  1. 点击顶部 "作品审核" 标签
  2. 找到刚才测试KOC提交的作品
  3. 查看作品详情

预期结果：

  • ✅ 看到测试KOC的提交记录
  • ✅ 状态显示"⏳ 待审核"
  • ✅ 可以点击"👁️ 查看"按钮查看详情
ℹ️ 关于评分

正常流程中，AI Agent会自动评分并把结果写入数据库。测试时我们跳过这步，直接用管理员手动加分功能模拟。

步骤 2.3：手动给测试KOC加分

操作：

  1. 点击顶部 "积分计算" 标签
  2. 找到测试KOC（通过Discord名称或UID搜索）
  3. 点击该KOC行的 "💳 积分" 按钮
  4. 在弹出的积分管理窗口中：
    • 选择 "加分"
    • 输入分数（如 20分）
    • 填写备注原因（如 "测试加分"）
    • 点击确认

预期结果：

  • ✅ 显示加分成功提示
  • ✅ KOC当月积分更新（显示20分）
  • ✅ 积分历史中显示加分记录
💡 为什么这样测试？

积分管理窗口可以手动增加/扣除积分，正常情况下用于特殊调整（如补发积分、纠正错误）。测试时我们用它来模拟AI评分的结果，这样可以快速完成测试流程。

步骤 2.4：开启兑换功能

操作：

  1. 在 "积分计算" 标签页
  2. 找到页面顶部的 "🔓 开放兑换" 按钮
  3. 点击按钮
  4. 确认

预期结果：

  • ✅ 按钮变为 "🔒 关闭兑换"
  • ✅ 按钮颜色变为红色
  • ✅ 显示"Redemption opened"
  • ✅ 前端KOC现在可以兑换奖励了
3
KOC前端 - 兑换奖励 创作者角色
步骤 3.1：查看更新后的积分

操作：

  1. 返回KOC前端页面
  2. 刷新页面（F5）
  3. 查看顶部积分显示

预期结果：

  • ✅ "Total Points" 显示20分
步骤 3.2：兑换钻石奖励

操作：

  1. 点击 "Redeem Rewards" 标签
  2. 选择 "💎 Diamonds" 子标签
  3. 选择一个钻石选项（如 600钻石=10分）
  4. 点击 "Redeem"
  5. 确认兑换

预期结果：

  • ✅ 显示"Redemption successful"
  • ✅ 如果积分不足，显示"Insufficient points"
步骤 3.3：查看兑换订单

操作：

  1. 点击 "My Orders" 标签
  2. 查看订单列表

预期结果：

  • ✅ 看到刚才兑换的订单
  • ✅ 订单状态：⏳ Pending
  • ✅ 显示花费的积分和奖励内容
4
Admin后台 - 订单处理 管理员角色
步骤 4.1：查看待处理订单

操作：

  1. 返回Admin后台
  2. 点击 "钻石兑换" 标签
  3. 找到测试KOC的订单

预期结果：

  • ✅ 看到待处理订单（状态为"pending"）
  • ✅ 订单显示KOC信息、奖励内容、积分花费
步骤 4.2：标记订单为已发货

操作：

  1. 在待处理订单行，点击 "✓" 按钮
  2. 在确认对话框中查看订单信息
  3. 点击"OK"确认发货

预期结果：

  • ✅ 订单状态变为"shipped"
  • ✅ 显示"Shipped + pts deducted"成功提示
  • ✅ 系统自动扣除相应积分
步骤 4.3：验证积分扣除

操作：

  1. 切换到 "积分计算" 标签
  2. 找到测试KOC
  3. 点击 "💳 积分" 查看积分历史

预期结果：

  • ✅ 积分历史中显示：
    • 加分记录：+20分（测试加分）
    • 扣分记录：-10分（兑换钻石）
  • ✅ 当前剩余积分：10分
✅
测试完成！

如果所有步骤都按预期运行，说明系统核心功能正常。请将测试结果和发现的问题反馈给项目负责人。
