KOC前端测试流程 创作者角色
步骤 1.1：首次注册

操作：

  1. 打开KOC前端页面
  2. 点击 "Register" 标签
  3. 填写注册信息：
    • Game UID：任意字母数字组合（如 "TestKOC001"）
    • Discord Name：你的Discord用户名
    • System ID：19位数字（如 "1234567890123456789"）
    • Full Name：测试用的姓名
    • Address：测试用的地址
  4. 点击 "Register" 按钮

预期结果：

  • ✅ 显示"Registration successful"成功提示
  • ✅ 自动跳转到提交作品页面
  • ✅ 页面顶部显示你的Game UID和当前积分（初始为0）
步骤 1.2：提交作品（第1次）

操作：

  1. 确保在 "Submit Works" 标签页
  2. 在文本框中粘贴测试链接（每行一个）：
https://www.tiktok.com/@test/video/123456 https://www.youtube.com/watch?v=test123 https://www.instagram.com/p/test456/
  1. 点击 "📤 Submit Works"
  2. 在弹出的确认框中点击 "OK"

预期结果：

  • ✅ 显示"Submitted X links successfully"成功提示
  • ✅ 提交计数器显示 "Submissions used: 1/2"
  • ✅ 文本框清空
⚠️ 注意事项

每月最多只能提交2次！请确认提交计数器正确显示。

步骤 1.3：查看已提交作品

操作：

  1. 点击 "My Submissions" 标签
  2. 查看提交记录列表

预期结果：

  • ✅ 看到刚才提交的3个链接
  • ✅ 每个链接显示：
    • 链接URL（可点击）
    • 提交时间
    • 状态：⏳ Pending
    • 积分：-（待审核）
步骤 1.4：提交作品（第2次）

操作：

  1. 返回 "Submit Works" 标签
  2. 再次粘贴不同的测试链接
  3. 提交

预期结果：

  • ✅ 提交成功
  • ✅ 提交计数器显示 "Submissions used: 2/2"
  • ✅ 文本框变为禁用状态（灰色）
  • ✅ 提交按钮也变为禁用状态
  • ✅ 显示提示："You have reached the submission limit for this month"
步骤 1.5：尝试第3次提交（应被阻止）

操作：

  1. 观察提交按钮是否已禁用
  2. 确认无法再提交新内容

预期结果：

  • ✅ 提交按钮保持禁用状态
  • ✅ 文本框无法输入
  • ✅ 系统正确限制了提交次数
步骤 1.6：等待管理员审核
ℹ️ 暂停KOC前端测试

现在需要切换到Admin后台，审核这些提交并给予积分。完成后再回到前端继续测试。

2
Admin后台测试流程 管理员角色
步骤 2.1：登录Admin后台

操作：

  1. 打开Admin后台页面
  2. 输入管理员密码（向项目负责人索取）
  3. 点击登录

预期结果：

  • ✅ 成功进入后台仪表盘
  • ✅ 看到顶部导航栏：Dashboard, 作品审核, 积分计算, 钻石兑换, 周边兑换, 谷歌礼品卡
  • ✅ Dashboard显示统计数据（KOC总数、待审核作品数等）
步骤 2.2：审核待审核作品

操作：

  1. 点击顶部 "作品审核" 标签
  2. 找到刚才KOC提交的作品（状态为"pending"）
  3. 点击作品链接查看内容（会在新标签页打开）
  4. 根据质量给予评分：
    • 在 "Points" 列输入分数（如 5分）
    • 点击分数框旁边的 "✓" 按钮确认
  5. 对所有待审核作品重复此操作

预期结果：

  • ✅ 作品状态从"pending"变为"approved"
  • ✅ 积分列显示刚才输入的分数
  • ✅ 作品行背景颜色变化（表示已审核）
💡 积分建议

测试时可以给每个作品3-10分不等，方便后续测试兑换功能。

步骤 2.3：查看积分计算模块

操作：

  1. 点击顶部 "积分计算" 标签
  2. 找到测试用的KOC（通过Discord名称或UID搜索）
  3. 查看该KOC的当月积分

预期结果：

  • ✅ 看到KOC的积分汇总（等于所有已审核作品的积分之和）
  • ✅ 显示订单状态（目前应该是"0 orders"）
  • ✅ 可以点击 "💳 积分" 按钮查看详细积分记录
步骤 2.4：开启兑换功能

操作：

  1. 在 "积分计算" 标签页
  2. 找到页面顶部的 "🔓 开放兑换" 按钮
  3. 点击按钮
  4. 在确认对话框中点击"OK"

预期结果：

  • ✅ 按钮文字变为 "🔒 关闭兑换"
  • ✅ 按钮颜色变为红色
  • ✅ 显示"Redemption opened"成功提示
  • ✅ 前端KOC现在可以兑换奖励了
⚠️ 重要

只有开启兑换后，KOC前端的"Redeem Rewards"标签才会显示可兑换的奖励。

步骤 2.5：测试CC自动检测功能（可选）
ℹ️ CC奖励说明

如果某个KOC当月提交了≥15个作品，系统会自动为其开启CC（持续创作）奖励。

操作：

  1. 在 "积分计算" 标签页
  2. 点击 "🔍 检测CC资格 (≥15)" 按钮
  3. 查看检测结果

预期结果：

  • ✅ 如果有KOC提交了≥15作品，会自动开启CC并创建奖励订单
  • ✅ 显示检测报告（哪些KOC获得了CC）
3
KOC前端测试 - 兑换奖励 创作者角色
步骤 3.1：查看更新后的积分

操作：

  1. 返回KOC前端页面
  2. 刷新页面（F5或Cmd+R）
  3. 查看页面顶部的积分显示

预期结果：

  • ✅ "Total Points" 显示更新后的积分（等于所有已审核作品的积分之和）
  • ✅ "My Submissions" 标签中，已审核作品的状态变为"✅ Approved"并显示获得的积分
步骤 3.2：兑换钻石奖励

操作：

  1. 点击 "Redeem Rewards" 标签
  2. 选择 "💎 Diamonds" 子标签
  3. 查看可兑换的钻石选项（如 300钻石=5分，600钻石=10分）
  4. 点击某个选项的 "Redeem" 按钮
  5. 在确认对话框中点击"OK"

预期结果：

  • ✅ 显示"Redemption successful"成功提示
  • ✅ 页面顶部的"Total Points"减少相应分数
  • ✅ 如果积分不足，会显示"Insufficient points"错误
步骤 3.3：查看兑换订单

操作：

  1. 点击 "My Orders" 标签
  2. 查看订单列表

预期结果：

  • ✅ 看到刚才兑换的订单
  • ✅ 订单显示：
    • 奖励名称（如"Diamonds x300"）
    • 花费的积分
    • 订单状态：⏳ Pending
    • 创建时间
步骤 3.4：测试其他兑换选项（可选）

操作：

  1. 返回 "Redeem Rewards"
  2. 尝试兑换其他类型的奖励：
    • "💳 Google Play Cards" - 谷歌礼品卡
    • "🎁 Merchandise" - 周边商品

预期结果：

  • ✅ 所有兑换类型都能正常工作
  • ✅ 积分正确扣除
  • ✅ 订单正确记录
4
Admin后台测试 - 订单管理 管理员角色
步骤 4.1：查看待处理订单

操作：

  1. 返回Admin后台
  2. 点击 "钻石兑换" 标签（如果KOC兑换的是钻石）
  3. 找到刚才KOC创建的订单（状态为"pending"）

预期结果：

  • ✅ 看到待处理的订单
  • ✅ 订单显示KOC的Discord名称、UID、奖励内容、积分花费
步骤 4.2：标记订单为已发货

操作：

  1. 在待处理订单行，点击 "✓" 按钮（Mark as Shipped）
  2. 在确认对话框中查看订单信息
  3. 点击"OK"确认发货

预期结果：

  • ✅ 订单状态从"pending"变为"shipped"
  • ✅ 显示"Shipped + pts deducted"成功提示
  • ✅ 系统自动扣除相应积分（在point_logs中记录）
  • ✅ ✓按钮消失（已发货订单不再显示此按钮）
💡 积分扣除逻辑

系统会自动检查是否已扣除积分，避免重复扣除。如果已扣除则跳过。

步骤 4.3：查看积分变化

操作：

  1. 切换到 "积分计算" 标签
  2. 找到测试KOC
  3. 点击 "💳 积分" 按钮查看积分历史

预期结果：

  • ✅ 积分历史中显示：
    • 赚取积分的记录（审核作品后）
    • 扣除积分的记录（发货后，显示为负数）
  • ✅ 当前剩余积分 = 总赚取积分 - 已兑换积分
✅ 测试完成检查清单

🐛 常见问题排查
问题1：提交作品后看不到记录

可能原因：

  • 网络延迟 - 等待几秒后刷新页面
  • 链接格式错误 - 确保使用支持的平台链接

解决方法：

  • 刷新页面（F5）
  • 检查浏览器控制台（F12）是否有错误信息
问题2：Admin后台无法登录

可能原因：

  • 密码输入错误
  • 浏览器缓存问题

解决方法：

  • 确认密码正确（向项目负责人确认）
  • 清除浏览器缓存后重试
问题3：兑换后积分没有扣除

可能原因：

  • 订单尚未发货 - 只有管理员标记发货后才会扣除积分

解决方法：

  • 这是正常行为！积分在管理员确认发货时才扣除
  • 在Admin后台标记订单为"shipped"即可触发扣除
问题4：页面加载很慢或显示错误

解决方法：

  • 检查网络连接
  • 尝试使用其他浏览器
  • 清除浏览器缓存
  • 按F12打开开发者工具，查看Console标签中的错误信息并报告给技术团队
